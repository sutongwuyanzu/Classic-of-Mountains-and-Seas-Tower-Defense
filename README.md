# 山海异兽志 · Classic of Mountains and Seas Tower Defense

这是一个独立重建的山海经主题塔防游戏，不是从 MakePlay 导出的原始工程。项目使用数据驱动的战斗逻辑、Canvas 绘制和 GPT Image 2 原创素材，复刻录屏中的核心玩法；当前优先打磨游戏本体，Steam 发行准备暂缓。

## 运行

需要 Python 3：

```bash
npm run dev
```

然后打开 `http://localhost:4173`。也可以直接双击 `index.html`；Windows 用户也可以双击 `start-game.cmd` 自动启动服务器并打开游戏。

## 当前方向

- 游戏本体：优先处理首局理解、战斗信息可读性、地图与波次策略、性能和稳定性；每项以实际游玩验证为准。
- Steam 桌面版：已有本地构建与发行资料保留，但不继续进行后台、商店或平台接入工作，直到本体达到验收标准。详见 `steam/README.md`。
- 微信小游戏：`wechatgame/` 和 `miniprogram/` 仅保留为兼容性参考，当前不继续开发或发布。

## 已实现

- 五个关卡使用覆盖全画面的独立长路线：洞窟回环、草原折返、沧海涡流、火山双线、云阶双线汇流；第四和第五关为双出怪口
- 五关均包含 15 波；第 5、10 波出现小首领，第 15 波清场后关卡首领降临
- 每关支持简单、中等、困难三档难度，联动调整敌军数量、生命、护甲、速度和免疫/复活/回血特性；抽卡概率不随难度变化；普通波间隔 7 秒，第 5/10/15 波提供 12 秒首领预警
- 战斗速度支持 1 倍和 2 倍；任意难度通关全部五关后永久解锁 3 倍速
- 自由坐标放置，避开道路、封印、裂隙和已有妖灵
- 27 只 N 至 UR 妖灵及独立立绘；普通召灵 20 二选一、高级召灵 50 三选一，两种模式均支持八折五连；中等高级池单格基准为 SR 92% / SSR 5% / UR 3%，候选去重不会把重复卡重掷成更高稀有度
- 每组候选最多置换两次：普通消耗 8/16 灵蕴，高级消耗 20/40 灵蕴；候选卡显示攻击属性、输出档、控制类型、固定/成长型和羁绊潜力
- 12 只妖灵拥有每局重置的成长被动；第 5、10 波后可选择攻击、技能循环或法域方向的局内技能进化
- Steam 版在完成任意标准关卡后开放无尽模式，并保存山海勋章；桌面存档写入 Electron 用户数据目录
- 微信激励广告仅用于每局一次免费置换、失败续关一次、结算功勋奖励加倍，不用于解锁妖灵或直接增加战斗属性
- 每只妖灵独立记录上场次数、击杀数与经验，灵阶提升会永久增加攻击、攻速和射程
- SR、SSR、UR 按关卡进度逐步进入召灵池；全中等与全困难通关分别解锁顶级 UR
- 转运签 30，包含友军增益、敌军增益、随机减益、灵蕴返还与谢谢惠顾
- 27 只妖灵均拥有消耗法力、带独立冷却的主动技能，以及影响周围友军的辅助技能；覆盖范围伤害、范围/指定眩晕、分裂、多重射、减速、破甲、攻击/攻速/射程、技能与法力恢复
- 13 个羁绊满足成员数量后上场即触发，不再要求阵型站位；每组羁绊均有独立主动技能，其中龙生九子拆分为三组，并补充 N、R 妖灵专属羁绊
- 结算采用总分与评级上限双判定：封印低于 30% 最高 C，低于 50% 最高 B，低于 80% 最高 A；必选妖灵或羁绊未完成时最高 A
- 光环、法力、技能冷却、索敌、追踪弹道、免疫、护甲、燃烧、减速、溅射、连锁；程序化分层音效覆盖召灵、部署、波次、首领、技能、击杀、破封、转运签和胜利反馈
- 复活和分裂敌人、击杀归属、局外修为本地存档
- 使用原创 GPT Image 2 五地貌、妖灵、敌人、封印与战斗特效素材
