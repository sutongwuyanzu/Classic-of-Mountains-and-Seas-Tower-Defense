# Steam 发售门禁

状态：仅用于本地发售准备；不是 Steam 后台操作说明，也不构成上传、送审、公开或发售授权。

本清单按“必须有实际证据”而非“文件已创建”判断。任一 P0 门禁未通过，候选包只能保留在本地或私有测试流程中。

## 当前结论

当前 Windows 候选包可本地构建和启动，但**不能送审或发售**。以下三项仍为 P0 阻断：

1. S05 压力场景尚未在物理显示器上得到达标的性能结果；远程虚拟显示环境的两次压力测试均未达预算，不能据此声明硬件要求。
2. S09 尚缺最终候选包、正常玩家流程拍摄的五张商店截图和正式胶囊图；现有 QA 画面仅供内部检查，禁止上传。
3. S10 尚无 Steamworks AppID、DepotID、后台权限和 Steam 客户端私测结果；模板和本地校验不等于 Steam 分发验证。

Steam 成就与云存档尚未接入。它们不是本次 Windows 单机首发的必选功能，但在商店页、截图和发行说明中不得承诺。

## 每次候选包复核

1. 在隔离目录重新构建，不将个人存档、源图、提示词、质检中间产物或账号文件装入包。
2. 重新生成并记录 EXE/包的 SHA-256、构建号、提交号和工作区状态；dirty 构建必须明确标注为 dirty。
3. 运行 `npm run check`、`npm run check:steampipe` 和 `git diff --check`；桌面产物必须实际启动。
4. 重新检查商店文案和截图不包含未交付的 Steam 功能、性能主张或错误的输入/平台承诺。
5. 仅在用户对本次外部操作作出明确授权后，执行上传、送审、公开或发售；此前通过任何本地门禁均不授予该权限。
