# 微信小程序版

这是不依赖网页服务器的原生 Canvas 版本，使用微信开发者工具打开本目录即可预览。

## 导入

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择当前 `miniprogram/`。
3. 没有正式 AppID 时可以先使用游客 AppID 预览；发布前替换 `project.config.json` 中的 AppID。
4. 在真机上测试触控放置、横向妖灵列表和双出怪口关卡。

## 当前玩法

- 五关分别为 8 / 9 / 9 / 9 / 12 波，第四、第五关会从两个独立裂口交替出怪。
- 普通召灵消耗 20 灵蕴，随机二选一；高级五连消耗 80 灵蕴，五只全部入卷且至少一只为 SR+。
- 背包最多保留 12 只待部署妖灵，场上人口上限 20；部署不会重复扣费。
- 收录 27 只 N 至 UR 妖灵、8 组羁绊和带权重的转运签结果。

## 发布前

- 在微信公众平台配置类目、隐私协议和合法的服务域名。
- 如果接入云存档、排行榜或支付，再补充云开发环境和隐私弹窗。
- 当前版本存档使用 `wx.setStorageSync`，不依赖外部接口。
